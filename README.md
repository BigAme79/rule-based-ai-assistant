# Smart Daily Assistant
 
This is a beginner-friendly rule-based AI system built with Python.
 
The assistant asks the user about:
 
- Weather
- Energy level
- Work schedule
 
Based on the answers, it recommends useful actions for the day.
 
## What This Project Demonstrates
 
- Rule-based AI logic
- If/else decision-making
- User input handling
- Basic command-line interface
- Python functions
- Simple project structure
 
## How to Run
 
Make sure Python is installed.
 
Run this command:
 
```bash
python3 smart_assistant.py
